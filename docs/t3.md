# t3code server

The `t3` image runs the [t3code](https://github.com/pingdotgg/t3code) server
with Claude Code and Codex in one long-lived container. The desktop and mobile
apps connect to it as a remote environment, so agents, terminals and git all
run inside the container.

## Install

`t3/t3.container` is a Podman Quadlet that runs the server as a systemd user
service on `127.0.0.1:3773`.

```sh
mkdir -p ~/.config/dev-containers/t3 ~/.config/containers/systemd
cp t3/t3.container ~/.config/containers/systemd/
systemctl --user daemon-reload
systemctl --user start t3
loginctl enable-linger "$(id -un)"   # keep it running after logout
```

Inside the container, `HOME` is your host home path, so project paths match
the host. Only `~/Code`, `~/.claude` and `~/.codex` are mounted from your real
home; add `Volume=` lines to the Quadlet for other project folders. The rest
of the home, including t3's data, lives in `~/.config/dev-containers/t3`.

To keep existing projects and threads from the desktop app, copy them in
before the first start, with the app closed:

```sh
mkdir -p ~/.config/dev-containers/t3/.t3
cp -a ~/.t3/userdata ~/.config/dev-containers/t3/.t3/
```

## Connect the apps

Get a pairing token with `podman exec t3 t3 pair`.

- **Desktop:** turn off *Settings → Environments → Local environment* so
  nothing runs on the host, then add `http://127.0.0.1:3773`.
- **Phone over Tailscale:** run `tailscale serve --bg 3773` on the host and add
  `https://<machine>.<tailnet>.ts.net`. Ignore the pairing URL `t3 pair`
  prints; that's the container's own address.

## Update

```sh
podman pull ghcr.io/recmanj/dev-containers/t3:latest
systemctl --user restart t3
```
